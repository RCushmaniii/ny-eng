## X / Twitter thread — Spanish

Five tweets. Post each block in order as a reply to the previous one.

Tweet 1

```
Un ingeniero mexicano con inglés C1 dice "Thursday" y su cliente en Estados Unidos le pregunta "Tuesday?"

No es el nivel de inglés.

Es que "Thursday" junta dos sonidos que el español no tiene, uno detrás del otro: TH + R.
```

Tweet 2

```
El problema más caro no es la TH.

Es el acento tónico:

thirTEEN — THIRty
fifTEEN — FIFty

Misma raíz, número distinto. Y ahí se van precios, edades, horarios de juntas y tiempos de entrega.
```

Tweet 3

```
Pista práctica, más fácil de controlar que el acento:

Las palabras en -TEEN terminan en N fuerte.
Las de -TY terminan en vocal suave.

Marque esa N final y la ambigüedad desaparece.
```

Tweet 4

```
Otra que casi nadie enseña:

"worked" tiene UNA sílaba. Igual que "work" con una T al final.

La -ED solo se vuelve sílaba propia después de un sonido T o D: wanted, needed, decided.

Si dice "work-ed", su interlocutor no oye pasado. Oye duda.
```
